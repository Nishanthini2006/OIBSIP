# Web Development and Designing Internship

## OIBSIP – Level 1 – Task 1

### Landing Page

This project is developed as part of the **Oasis Infobyte Web Development and Designing Internship – Level 1, Task 1**.

The objective of this task is to design and develop a professional and attractive **Landing Page** using front-end web development technologies. The project focuses on creating a clean layout, proper navigation, visually appealing sections, and a user-friendly interface.

## 📌 Project Overview

The Landing Page is designed to demonstrate the fundamental concepts of web development, including webpage structure, styling, layout design, navigation, typography, spacing, and responsive presentation.

The page contains a structured navigation bar, attractive hero section, informative content sections, and a visually consistent design to provide a smooth user experience.

## 🎯 Task Objective

The main objective of this task is to:

* Create an attractive and professional Landing Page.
* Apply proper HTML structure and CSS styling.
* Design a clear and user-friendly navigation section.
* Organize webpage content into meaningful sections.
* Use appropriate typography, spacing, colors, and layouts.
* Create a visually appealing front-end design.
* Demonstrate practical knowledge of HTML and CSS.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the webpage.
* **CSS3** – Used for styling, layout, colors, spacing, typography, and visual presentation.

# Web Development and Designing Internship

## OIBSIP – Level 1 – Task 3

### Temperature Converter Website

This project is developed as part of the **Oasis Infobyte Web Development and Designing Internship – Level 1, Task 3**.

The objective of this task is to design and develop a functional and user-friendly **Temperature Converter Website** that allows users to convert temperature values between different units such as Celsius, Fahrenheit, and Kelvin.

## 📌 Project Overview

The Temperature Converter Website is designed to provide a simple and interactive way to convert temperature values from one unit to another.

Users can enter a temperature value, select the input temperature unit, and convert the value into the corresponding temperature units. The website provides the converted result in a clear and easy-to-understand format.

This project demonstrates the practical implementation of HTML, CSS, and JavaScript to create an interactive front-end web application.

## 🎯 Task Objective

The main objectives of this task are:

- To create a functional Temperature Converter Website.
- To design a clean and user-friendly interface.
- To use HTML5 for structuring the webpage.
- To use CSS3 for styling and layout design.
- To use JavaScript for temperature conversion functionality.
- To allow users to select different temperature units.
- To convert temperature values accurately.
- To display conversion results clearly.
- To provide a smooth and interactive user experience.
- To demonstrate practical knowledge of front-end web development.

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure and elements of the webpage.
- **CSS3** – Used for styling, layout, spacing, typography, and visual presentation.
- **JavaScript** – Used to implement temperature conversion logic and interactive functionality.

## 🌡️ Temperature Units

The converter supports the following temperature units:

- **Celsius (°C)**
- **Fahrenheit (°F)**
- **Kelvin (K)**

Users can select the required input unit and enter a temperature value to perform the conversion.

## ✨ Key Features

- Simple and user-friendly interface
- Temperature input field
- Input Unit selection
- Celsius conversion
- Fahrenheit conversion
- Kelvin conversion
- Accurate temperature calculations
- Interactive Convert Temperature button
- Clear conversion result
- Responsive-friendly layout
- Clean and professional design
- JavaScript-based functionality

## 🔄 Conversion Functionality

The application performs temperature conversions based on the selected input unit.

For example:

- Celsius can be converted into Fahrenheit and Kelvin.
- Fahrenheit can be converted into Celsius and Kelvin.
- Kelvin can be converted into Celsius and Fahrenheit.

The conversion calculations are handled using JavaScript to provide immediate results without reloading the webpage.

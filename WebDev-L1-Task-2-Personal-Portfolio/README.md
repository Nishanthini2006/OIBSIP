# Web Development and Designing Internship

## OIBSIP – Level 1 – Task 2

### Personal Portfolio Website

This project is developed as part of the **Oasis Infobyte Web Development and Designing Internship – Level 1, Task 2**.

The objective of this task is to design and develop a professional and responsive **Personal Portfolio Website** that presents personal information, skills, services, projects, and contact details in a clear and attractive manner.

## 📌 Project Overview

The Personal Portfolio Website is designed to provide an online professional profile and showcase web development skills and projects.

The website contains different sections that introduce the developer, highlight technical skills, present services and projects, and provide contact and social media information.

The project focuses on creating a clean, modern, user-friendly, and visually appealing portfolio using front-end web development technologies.

## 🎯 Task Objective

The main objectives of this task are:

- To create a professional Personal Portfolio Website.
- To build a well-structured webpage using HTML5.
- To apply modern styling and layouts using CSS3.
- To use JavaScript for interactive webpage elements.
- To organize personal information in a clear and professional format.
- To showcase technical skills and projects.
- To provide contact and social media information.
- To create a responsive and user-friendly interface.
- To demonstrate practical front-end web development skills.

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure and content of the portfolio.
- **CSS3** – Used for styling, layout, colors, typography, spacing, animations, and responsive design.
- **JavaScript** – Used to add interactivity and dynamic functionality to the webpage.
